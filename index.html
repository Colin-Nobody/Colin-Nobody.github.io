Current research

GUVP — Pairwise Ranking for Visual Pollution

View project →

GUVP studies visual pollution in street-view images. It turns pairwise judgements about which scene looks cleaner into image-level rankings. The project combines Q-score and TrueSkill aggregation with vision-language model evaluation, using evidence-based scoring and swapped image positions to help reduce A/B position bias.
